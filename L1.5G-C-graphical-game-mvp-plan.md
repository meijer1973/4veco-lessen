## MVP Cut

Implement only these challenge types:

- `bar_value_read`: read one value from a bar chart;
- `line_value_read`: read one value from a line chart;
- `graph_values_percentage_change`: select old/new graph values and calculate
  the percentage change.

Use `1.1.2 Percentages en indexcijfers` as the technical pilot. L1.6 remains
the fresh paragraph proof, preferably `1.1.3 Grafieken en tabellen`.
