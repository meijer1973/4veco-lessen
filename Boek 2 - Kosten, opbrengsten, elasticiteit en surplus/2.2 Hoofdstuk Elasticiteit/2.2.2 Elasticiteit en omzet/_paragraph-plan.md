# Paragraph Plan: 2.2.2 Elasticiteit en omzet

## Scope

This paragraph teaches how price elasticity affects omzet. It does not promote the target record and does not start 2.2.3, 2.2.4, Chapter 2.3, or Book 3.

## Target Route

Students learn to:

1. calculate `TO = P x Q` before a price change;
2. calculate `TO = P x Q` after a price change;
3. compare old and new omzet;
4. connect the omzet change to signed `Ev` and classification with `|Ev|`;
5. apply the omzet rule for price increases and price decreases;
6. give bounded pricing advice without using profit or cost reasoning.

## Visual Assignment

No image figures are used in this paragraph. The visual support is built from rendered markdown tables:

- before/after omzet tables;
- a decision-rule table for elastic, inelastic, and unitair elastisch demand;
- answer-structure tables.

This keeps the paragraph within the readiness brief's preference for simple, readable visuals.

## Terminology

- Use `TO` for totale omzet.
- Use `TO = P x Q` in student-facing formulas.
- Use signed `Ev` first, then `|Ev|` for elastic/inelastic classification.
- Use "old value" as denominator for percentage changes.
- Use "omzetadvies" or "prijsadvies voor omzet"; do not turn it into a profit, cost, or margin decision.
