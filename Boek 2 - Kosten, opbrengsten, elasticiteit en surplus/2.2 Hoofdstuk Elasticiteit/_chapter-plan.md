# Chapter Plan: 2.2 Elasticiteit

## Scope

This chapter slice contains only `2.2.1 Prijselasticiteit`.

Later paragraph folders for 2.2.2, 2.2.3, and 2.2.4 were present in a stale untracked candidate bundle at sprint opening. They are not accepted as proof and are not included in this chapter assembly.

## Student Route

The 2.2.1 route teaches students to:

- identify old and new values for price and quantity demanded;
- calculate percentage changes using the old value as denominator;
- calculate signed `Ev`;
- classify demand with `|Ev|`;
- end the answer with a plain-language economic interpretation.
