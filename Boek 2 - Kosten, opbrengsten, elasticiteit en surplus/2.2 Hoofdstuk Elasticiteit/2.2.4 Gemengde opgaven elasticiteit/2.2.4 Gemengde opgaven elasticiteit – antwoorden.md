# 2.2.4 Gemengde opgaven: elasticiteit - antwoorden

## Startopgave 1 - Bioscoop Lux

**A.**

`%dP = (12 - 10) / 10 x 100% = 20%`

De prijs stijgt met 20%.

**B.**

`%dQv = (420 - 500) / 500 x 100% = -16%`

De gevraagde hoeveelheid daalt met 16%.

**C.**

`Ev = %dQv / %dP = -16% / 20% = -0,8`

**D.**

`|Ev| = 0,8`. Omdat `0,8 < 1`, is de vraag inelastisch. Bezoekers reageren procentueel minder sterk dan de prijs stijgt.

**E.**

Voor de prijsverhoging:

`TO = 10 x 500 = 5000 euro`

Na de prijsverhoging:

`TO = 12 x 420 = 5040 euro`

**F.**

De omzet stijgt omdat de vraag inelastisch is. De prijs stijgt procentueel sterker dan de hoeveelheid daalt.

## Startopgave 2 - Lunchproducten

**A.**

`Ei = %dQv / %dY = 8% / 5% = 1,6`

**B.**

De luxe salade is een normaal goed, want `Ei` is positief. Het is ook een luxe goed, want `Ei > 1`.

**C.**

`Ei = -3% / 5% = -0,6`

**D.**

Budgetnoedels zijn een inferieur goed, want `Ei` is negatief. De vraag daalt als het inkomen stijgt. De indeling luxe of noodzakelijk gebruik je alleen bij normale goederen.

## Startopgave 3 - Koffie, thee en filters

**A.**

`Ek = %dQv thee / %dP koffie = 4% / 10% = 0,4`

**B.**

Koffie en thee zijn substituten. `Ek` is positief: als koffie duurder wordt, stijgt de vraag naar thee.

**C.**

`Ek = %dQv filters / %dP koffie = -6% / 10% = -0,6`

**D.**

Koffie en koffiefilters zijn complementen. `Ek` is negatief: als koffie duurder wordt, daalt de vraag naar filters.

## Opgave 4 - SportSchool Fit & Go

**A.**

`%dP = (30 - 25) / 25 x 100% = 20%`

**B.**

`%dQv = (1020 - 1200) / 1200 x 100% = -15%`

**C.**

`Ev = -15% / 20% = -0,75`

`|Ev| = 0,75`, dus de vraag is inelastisch.

**D.**

Voor de prijsverhoging:

`TO = 25 x 1200 = 30.000 euro`

Na de prijsverhoging:

`TO = 30 x 1020 = 30.600 euro`

De omzet stijgt met 600 euro.

**E.**

De uitspraak is te kort door de bocht. De omzet stijgt bij deze prijsverhoging omdat de vraag inelastisch is, maar dat betekent niet dat elke verdere prijsverhoging goed is. Bij hogere prijzen kunnen leden sterker afhaken. Bovendien zegt omzet niets over kosten, winst en klanttevredenheid.

## Opgave 5 - Koffiebar Campus

De vraagfunctie is:

`Q = 5000 - 200P + 0,03Y + 150Pc`

**A.** Beginsituatie: `P = 8`, `Y = 40.000`, `Pc = 6`.

`Q = 5000 - 200 x 8 + 0,03 x 40.000 + 150 x 6`

`Q = 5000 - 1600 + 1200 + 900 = 5500`

De gevraagde hoeveelheid is 5500 ijskoffies.

**B.** Nieuwe prijs: `P = 9`.

`Q = 5000 - 200 x 9 + 0,03 x 40.000 + 150 x 6`

`Q = 5000 - 1800 + 1200 + 900 = 5300`

**C.**

`%dP = (9 - 8) / 8 x 100% = 12,5%`

`%dQv = (5300 - 5500) / 5500 x 100% = -3,6%`

`Ev = -3,6% / 12,5% = -0,29`

De vraag is inelastisch.

**D.** Nieuw inkomen: `Y = 42.000`.

`Q = 5000 - 200 x 8 + 0,03 x 42.000 + 150 x 6`

`Q = 5000 - 1600 + 1260 + 900 = 5560`

**E.**

`%dY = (42.000 - 40.000) / 40.000 x 100% = 5%`

`%dQv = (5560 - 5500) / 5500 x 100% = 1,1%`

`Ei = 1,1% / 5% = 0,22`

Ijskoffie is volgens deze gegevens een normaal noodzakelijk goed, want `Ei` is positief en kleiner dan 1.

**F.** Nieuwe prijs concurrent: `Pc = 7`.

`Q = 5000 - 200 x 8 + 0,03 x 40.000 + 150 x 7`

`Q = 5000 - 1600 + 1200 + 1050 = 5650`

**G.**

`%dPc = (7 - 6) / 6 x 100% = 16,7%`

`%dQv = (5650 - 5500) / 5500 x 100% = 2,7%`

`Ek = 2,7% / 16,7% = 0,16`

Ijskoffie en frisdrank zijn substituten, want `Ek` is positief. Als frisdrank duurder wordt, stijgt de vraag naar ijskoffie.

## Doeloefening - StreamPlus

### Bron 1 - Prijs, abonnees en extra informatie

**A.**

Voor `Ev` gebruik je de maandprijs en het aantal standaardabonnees. De app-score en wachttijd zijn niet nodig voor de elasticiteitsberekening, al kunnen ze wel relevant zijn voor een breder advies.

**B.**

`%dP = (12 - 10) / 10 x 100% = 20%`

`%dQv = (43.000 - 50.000) / 50.000 x 100% = -14%`

`Ev = -14% / 20% = -0,7`

**C.**

`|Ev| = 0,7`, dus de vraag is inelastisch. De hoeveelheid abonnees daalt procentueel minder sterk dan de prijs stijgt.

**D.**

Voor de prijsverhoging:

`TO = 10 x 50.000 = 500.000 euro`

Na de prijsverhoging:

`TO = 12 x 43.000 = 516.000 euro`

De omzet stijgt met 16.000 euro. Dat past bij een inelastische vraag: de prijsstijging is procentueel groter dan de daling van het aantal abonnees.

### Bron 2 - Inkomen en abonnementstypen

**E.** Premium:

`%dQv = (13.800 - 12.000) / 12.000 x 100% = 15%`

`Ei = 15% / 8% = 1,875`

Premium is een normaal luxe goed, want `Ei` is positief en groter dan 1.

**F.** Budget:

`%dQv = (19.200 - 20.000) / 20.000 x 100% = -4%`

`Ei = -4% / 8% = -0,5`

Budget is een inferieur goed, want `Ei` is negatief. De luxe/noodzakelijk-indeling gebruik je hier niet.

### Bron 3 - Concurrentie als gestructureerde bron

**G.**

`%dP concurrent = (9 - 8) / 8 x 100% = 12,5%`

`%dQv StreamPlus = (45.150 - 43.000) / 43.000 x 100% = 5%`

`Ek = 5% / 12,5% = 0,4`

**H.**

StreamPlus en de concurrent zijn substituten. De prijs van de concurrent stijgt en de vraag naar StreamPlus stijgt ook. Dat past bij een positieve kruiselingse elasticiteit.

### Bron 4 - Vraagfunctie

De vraagfunctie is:

`Q = 12.000 - 400P + 0,1Y + 300Pc`

**I.** Beginsituatie: `P = 12`, `Y = 40.000`, `Pc = 10`.

`Q = 12.000 - 400 x 12 + 0,1 x 40.000 + 300 x 10`

`Q = 12.000 - 4.800 + 4.000 + 3.000 = 14.200`

**J.** Inkomen stijgt naar `Y = 42.000`.

`Q = 12.000 - 4.800 + 4.200 + 3.000 = 14.400`

`%dY = (42.000 - 40.000) / 40.000 x 100% = 5%`

`%dQv = (14.400 - 14.200) / 14.200 x 100% = 1,4%`

`Ei = 1,4% / 5% = 0,28`

Volgens de vraagfunctie is het standaardabonnement een normaal noodzakelijk goed.

**K.** Concurrentieprijs stijgt naar `Pc = 11`.

`Q = 12.000 - 4.800 + 4.000 + 3.300 = 14.500`

`%dPc = (11 - 10) / 10 x 100% = 10%`

`%dQv = (14.500 - 14.200) / 14.200 x 100% = 2,1%`

`Ek = 2,1% / 10% = 0,21`

De diensten zijn substituten volgens de vraagfunctie.

**L.**

StreamPlus moet niet automatisch doorgaan met prijsverhogingen. Bron 1 laat zien dat deze prijsverhoging de omzet verhoogde, omdat de vraag inelastisch was. Bron 3 en bron 4 laten zien dat de vraag ook afhangt van concurrentie. De lagere app-score en langere wachttijd uit bron 1 zijn geen elasticiteitsberekening, maar ze waarschuwen dat klanttevredenheid kan meespelen. Uit deze bronnen weten we niet wat de kosten, winst of langetermijnbinding zijn. Een voorzichtig advies is daarom: kleine prijsstappen testen, concurrentie en opzeggingen volgen, en omzet niet verwarren met winst.

## Denkertje - Prijsverlaging en omzet

**A.**

`%dQv = Ev x %dP = -0,4 x -10% = 4%`

De gevraagde hoeveelheid stijgt met 4%.

**B.**

De omzet daalt waarschijnlijk. De prijs daalt met 10%, maar de hoeveelheid stijgt maar met 4%. Bij inelastische vraag helpt een prijsverlaging de omzet meestal niet.

**C.**

`%dQv = -1,8 x -10% = 18%`

De gevraagde hoeveelheid stijgt met 18%.

**D.**

Nu is de vraag elastisch. De hoeveelheid stijgt procentueel sterker dan de prijs daalt. Daardoor kan de omzet stijgen.
