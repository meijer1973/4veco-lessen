# Paragraph Plan: 2.2.1 Prijselasticiteit

## Scope

This paragraph teaches price elasticity of demand only. It does not promote the target record and does not start later elasticity paragraphs.

## Target Route

Students learn to:

1. write old and new values for `P`;
2. calculate `%dP` with the old price as denominator;
3. write old and new values for `Qv`;
4. calculate `%dQv` with the old quantity as denominator;
5. calculate signed `Ev = %dQv / %dP`;
6. classify with `|Ev|`;
7. explain the meaning in context.

## Terminology

- Use `Ev` for price elasticity of demand.
- Use `%dP` and `%dQv` in student-facing formulas to avoid symbol encoding ambiguity.
- Use signed `Ev` first, then `|Ev|` for classification.
- Use "old value" as denominator for every percentage change.
