## Strategic Implementation Decision

Do not rename or delete existing lesson folders during L1.5P.

The clean implementation path is a platform-owned print assembly path:

1. Update the Book 1 print manifest and voorwoord in the platform repo.
2. Extend the platform book builder only if needed so it can compose the printed
   book from a curated 12-paragraph print scope while leaving the broader online
   lesson tree intact.
3. Generate the book-level markdown, HTML, PDF, and assets into
   `4veco-lessen`.
4. Add a print-scope validator so the printed book cannot silently include
   chapter 1.4, chapter 1.5, test-preparation, or marginal-analysis TOC rows.

This keeps the distinction clear:

- `4veco-lessen` keeps the reachable online/archive material.
- `4veco-platform` owns the print assembly and validation logic.

## Procedure

1. Add or update the platform print-scope mechanism.
2. Update the Book 1 manifest to the new 12-paragraph print scope.
3. Update the platform voorwoord:
   - remove "five chapters";
   - remove printed Chapter 5 / test-preparation wording;
   - say test preparation is online;
   - say the formal test is about Book 1.
4. Generate the Book 1 book output through:

   ```powershell
   python build-scripts/books/build-book.py --book 1
   ```

5. Run focused print-scope validation.
6. Run Book 1 health checks.
7. Record the survival map and closure log.
8. Commit platform changes first, then generated lesson output/bookkeeping.

- `check:book` and print-scope validation pass.
- No generated output is hand-patched.

## Stop Conditions

Stop and report before implementation if:

- the print cut requires deleting or renaming existing 1.4/1.5 lesson folders;
- the only viable path is hand-editing `Boek 1 ... - boek.md` or chapter
  `hoofdstuk.md` output directly;
- the revised 1.3.4 mixed-opgaven content cannot be produced without a content
  decision beyond supply/demand/equilibrium/shifts;
- the book builder cannot be extended cleanly without breaking existing
  chapter-based manifests;
- validation shows the online/parked material is no longer reachable.
