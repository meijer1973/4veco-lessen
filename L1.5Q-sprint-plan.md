# L1.5Q Sprint Plan - Course Blueprint v5 + Four Test-Week Book Plan

Date: 2026-05-18
Status: ACTIVE PLAN

## Goal

Create the authoritative v5 curriculum source for the new school-year model:

- four books map to four formal test weeks;
- printed books have count-bearing paragraph budgets of 12 / 12 / 14 / 16;
- test-preparation packages are web-only and not printed chapters;
- Book 1 follows the L1.5P 12-paragraph print scope;
- parked material from Book 1 has a clear migration route;
- the platform target-exercise source-of-truth path is no longer ambiguous
  after v5 becomes authoritative.

L1.5Q is executed in two internal phases:

- **Phase A - Source-of-truth migration seam.** Make the platform capable of
  treating v5 as the active curriculum source before the richer pedagogical
  rewrite is completed.
- **Phase B - Blueprint v5 content migration.** Finish the v5 curriculum prose,
  migration tables, target-exercise placeholders/finals, derived reference
  outputs, and closure log.

Phase A must pass before Phase B can close.

## Target V5 Structure

### Book Counts

| Book | Count-bearing paragraphs | Formal test-week scope |
| --- | ---: | --- |
| Book 1 | 12 | Test week 1: Book 1 |
| Book 2 | 12 | Test week 2: Book 2 |
| Book 3 | 14 | Test week 3: Book 3 |
| Book 4 | 16 | Test week 4: Book 4 |

Test preparation is web-only for every book. Optional mid-book checks may exist
as formative diagnostics or web quizzes, not as printed chapters and not as
separate formal test-week scopes.

### Book 1 Fixed Scope

Book 1 uses the L1.5P print scope:

- 1.1.1 Schaarste en economisch denken
- 1.1.2 Percentages en indexcijfers
- 1.1.3 Grafieken en tabellen
- 1.1.4 Gemengde opgaven
- 1.2.1 Individuele vraag
- 1.2.2 Vraagfactoren
- 1.2.3 Van individuele naar collectieve vraag
- 1.2.4 Gemengde opgaven
- 1.3.1 Aanbod
- 1.3.2 Marktevenwicht
- 1.3.3 Verschuivingen en nieuw evenwicht
- 1.3.4 Gemengde opgaven

### Migration Rules

- Book 1 costs/revenue/marginal-analysis material is not deleted; it is parked
  for Book 2/3 migration.
- `1.3.2 Kostenstructuren`, `1.3.3 Opbrengsten`, and `1.4.3 Marginale kosten
  en marginale opbrengsten` move out of Book 1.
- `1.4.4 Winstmaximalisatie` moves out of Book 1 and is expected later with
  production/market-structure work.
- `1.5 Toetsvoorbereiding` remains web-only.
- Government intervention, monopoly, market failure, and later macro/inflation
  content must be resequenced without cramming oversized paragraphs.

## Implementation Procedure

### Phase A - Source-of-truth migration seam

1. Archive the current v4 target-exercise registry as historical evidence.
2. Create/mirror a v5 blueprint scaffold and v5 metadata so the active registry
   can point to a real owned source.
3. Update the active target-exercise registry at the stable path
   `references/authored/course-target-exercises.json` so it says:
   - `blueprint_version: "v5"`;
   - `blueprint_source: "references/owned/course-blueprint-v5.md"`;
   - 54 count-bearing records.
4. Add explicit placeholder semantics:
   - `paragraph_kind`;
   - `introduces_new_theory`;
   - `record_status`;
   - placeholder reason where a target exercise is not reviewed final.
5. Ensure gemengde-opgaven paragraphs are count-bearing records, with
   `paragraph_kind: "gemengde_opgaven"` and `introduces_new_theory: false`.
6. Update platform reference builders/checkers so v5 is read from the active
   target-exercise metadata rather than from brittle v4 filename constants.
7. Add or update validation so v5 cannot claim authority unless:
   - blueprint counts are exactly 12 / 12 / 14 / 16;
   - every count-bearing paragraph has a target exercise or explicit
     placeholder;
   - test-preparation packages are web-only and excluded from counts.
8. Regenerate any derived reference artifacts required by changed platform
   builders/checkers.
9. Write `L1.5Q-phase-a-source-of-truth-log.md`.

### Phase B - Blueprint v5 content migration

1. Finish the v5 blueprint prose as a new versioned file in the lesson repo.
2. Keep the platform owned v5 blueprint and metadata aligned with that source.
3. Create the migration table that records every moved/parked paragraph and its
   intended destination or status.
4. Review or intentionally leave placeholder target exercises as placeholders.
5. Update roadmap and closure log only after validators pass.

## Acceptance Criteria

- `course_blueprint_v5.md` exists and states the four-book/four-test-week model.
- The v5 blueprint has exact paragraph counts: 12 / 12 / 14 / 16.
- Test-preparation chapters are marked as web-only packages, not printed
  chapters and not count-bearing paragraphs.
- The Book 1 table of contents matches L1.5P.
- The migration table records every Book 1 cut item and the broader forward
  shifts named in the roadmap.
- Every count-bearing paragraph has a target exercise or explicit placeholder.
- Every placeholder is visibly non-final and cannot be mistaken for a reviewed
  final target exercise.
- The active platform target-exercise reference is no longer ambiguous about
  whether v4 or v5 is authoritative.
- Reference builders/checkers that hardcoded v4 are updated or a documented
  stop condition prevents closure.
- JSON and markdown hygiene checks pass.
- Full relevant platform reference checks pass, or any unavailable check is
  explicitly logged with a reason and next action.

## Stop Conditions

- Stop if the 54-paragraph v5 structure cannot be defined without cramming
  moved theory into oversized paragraphs.
- Stop if updating `course-target-exercises.json` would invalidate reference
  governance without a matching platform checker update.
- Stop if platform reference builders require a broader owned-source migration
  than this sprint can safely complete.
- Stop if any target-exercise placeholder would be mistaken for a reviewed final
  target exercise. Placeholders must be visibly marked.
