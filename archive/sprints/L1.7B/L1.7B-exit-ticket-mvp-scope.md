# L1.7B Exit-Ticket MVP Scope

Date: 2026-05-23
Status: FUTURE MVP SCOPE; NOT IMPLEMENTED IN L1.7B

## Pilot Paragraph

Preferred pilot:

```text
1.1.1 Schaarste en economisch denken
```

Rationale:

- the existing prototype targets `1.1.1`;
- the paragraph has stable current validation;
- it covers verbal reasoning and calculation, making it a useful checkpoint
  pilot before graph-heavy variants.

Constraint:

The existing prototype source cites older `v4` blueprint wording and must be
reconciled with the current v5 target-exercise baseline before implementation.

## MVP Shape

The MVP should be a compact retrieval/checkpoint surface:

- 3-5 tasks;
- no full test environment;
- no grade, percentage, pass threshold, or mastery banner;
- plain feedback per task;
- a final reflection panel with:
  - what went well;
  - what to practise next;
  - suggested game route: Redeneren, Rekenen, Grafieken;
  - no automatic routing or diagnosis.

## Task Types

Allowed MVP task types:

- calculation with separate fields:
  - calculation;
  - answer;
  - unit;
- multiple choice only when it checks a reasoning distinction;
- short open response with rubric-like feedback, carefully framed as practice
  feedback.

Avoid:

- high-stakes correction-model framing;
- "all-or-nothing" mastery language;
- copied evidence payloads;
- teacher approval claims;
- hidden adaptive focus.

## UI Language Rules

Allowed phrases:

- `Exit ticket`
- `Korte check`
- `Controleer je aanpak`
- `Feedback`
- `Nog oefenen`
- `Kies een oefenroute`
- `Probeer een nieuwe variant`

Banned or blocked phrases:

- `Mastery`
- `Beheersing aangetoond`
- `Mastery-eis`
- `Score`
- `Cijfer`
- `Geslaagd`
- `Gezakt`
- `Summatief`
- `Diagnose`
- `Adaptieve focus`
- `Kopieer resultaat als bewijs`
- `Machine evidence`

## Human Review Gate

The MVP cannot enter the scalable companion contract until review records
exist:

- student-experience review;
- teacher-learning-quality review;
- lead-review summary;
- closure or pause log.

Casual approval or a generic "continue" is not a review gate.
