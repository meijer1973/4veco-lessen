## Implementation Summary

The landing generator now distinguishes between scoped and unscoped skill-tree
math pages.

- If `wiskundevaardigheden.html` exists and the paragraph declares concrete
  skill-tree skills, the primary `Rekenen` route links to the skill-tree math
  game.
- `stappenplan.html` remains visible as `Rekenstappen` support and is no
  longer labelled as the replacement `Rekenen` route.
- If `wiskundevaardigheden.html` exists but the skill-tree configuration is
  unscoped/full-catalog, it is not promoted to primary `Rekenen`; it is shown
  only as `Brede vaardigheidskaart` under secondary material.
- The old `Volledige vaardigheidskaart` card wording was removed from ordinary
  scoped math routes.
- The screenshot QA helper now recognizes skill-tree and reasoning game pages,
  so visual QA can catch whether those surfaces actually render.
