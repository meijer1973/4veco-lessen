# L1.5P Lead Review Record

Date: 2026-05-18
Status: PASS AFTER CORRECTION

## Review Trigger

After L1.5P was first closed, an independent lead review was requested before
moving to L1.5Q. The review found that the first closure was too optimistic:
the print TOC was correct, but the generated body and validator were not yet
strong enough.

## Initial Lead-Review Verdict

Initial verdict: REVISE.

Findings:

- The generated Book 1 body still contained excluded cost/marginal-analysis
  material, including a cost-structure exercise and marginal-revenue glossary
  content.
- Composed chapter 1.3 duplicated `## Opgaven` sections because reused
  paragraph files already contained opgaven and the manifest appended separate
  opgaven files again.
- The print-scope validator checked old-scope terms in the TOC, but did not
  scan visible body/back-matter text or duplicate exercise sections.

## Corrections Applied

Corrections were made in platform source and the book was regenerated:

- `book-1.json`
  - changed reused composed paragraphs to include only `paragraaf` because the
    source paragraph files already contain their opgaven;
  - added print-only text replacements for stale transition sentences;
  - removed the 1.4.2 cost-structure interleaving exercise from print output;
  - excluded parked formal glossary terms that belong to later books.
- `lib_book.py`
  - added manifest-controlled text-removal support for composed print chapters;
  - added manifest-controlled glossary exclusions.
- `check-book-print-scope.js`
  - now scans visible markdown body/back matter, ignoring internal asset paths;
  - fails on visible old 1.4/1.5 paragraph references;
  - fails on excluded cost, marginal, producer-surplus, and formal revenue
    formulas;
  - fails when a paragraph has duplicate `## Opgaven` sections.
- `check-book-print-scope.test.js`
  - added negative tests for forbidden body content and duplicate opgaven.
