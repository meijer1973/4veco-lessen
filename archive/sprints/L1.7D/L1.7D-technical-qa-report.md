# L1.7D Technical QA Report

Date: 2026-05-24
Status: TECHNICAL QA GREEN; READY FOR HUMAN REVIEW; NOT CLOSED

## Scope

L1.7D implements the paragraph landing-page information architecture cleanup.
The sprint changes how generated paragraph landing pages present companion
surfaces. It does not change Part A prose, Part A PDFs, target exercises, or
protected reference data.

## Implementation Summary

- Updated the platform landing-page generator so paragraph pages use
  `data-layout="paragraaf-v2"` and route layers:
  `Start`, `Leer`, `Oefen`, optional `Check`, and `Verdiep`.
- `Check` remains hidden unless a real exit-ticket/checkpoint HTML surface is
  present.
- `Oefen` now separates guided support from scoped practice routes:
  `Redeneren`, `Rekenen / stappenplan`, and `Grafieken` where available.
- The full skill-map page is demoted to a collapsed `Volledige
  vaardigheidskaart` source item when a `stappenplan` calculation/procedure
  route exists.
- Summary/news/presentation/textbook/source material is grouped under collapsed
  `Verdiep` secondary sections instead of appearing as equal first-layer cards.
- Existing student-facing Word exercise rows remain hidden from generated
  paragraph landing pages.
- Chapter and book availability tags now use the route-language labels produced
  by the paragraph generator.
- Student-web screenshot QA now recognizes paragraph route layers instead of
  requiring every landing page to expose a graph route.

Platform support commit: `17dd80f` (`Implement L1.7D landing route IA`).
