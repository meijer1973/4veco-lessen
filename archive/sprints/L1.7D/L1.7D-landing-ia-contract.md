# L1.7D Landing Information Architecture Contract

Date: 2026-05-24
Status: CONTRACT FOR IMPLEMENTATION

## Route Layers

| Layer | Default visibility | Student role | Surfaces |
| --- | --- | --- | --- |
| `Start` | primary | Orient and activate prior knowledge | `instapquiz`, `uitleg voorkennis` |
| `Leer` | primary | Learn the main skill/procedure | `uitleg vaardigheden` |
| `Oefen` | primary group | Practise with support and scoped game routes | `begeleide inoefening`, `Redeneren`, `Stappenplan/Rekenen`, `Grafieken` |
| `Check` | hidden unless available | Non-summative checkpoint | exit ticket after a future reviewed MVP |
| `Verdiep` | secondary/collapsed | Reinforce, contextualize, and access sources/downloads | `samenvatting`, `nieuws met visual`, `nieuws-detective`, `YouTube`, `presentatie`, `lesboek`, PDFs, full skill map |

## Default Visibility Rule

The default landing page should show enough for a student to start and continue:

```text
Start -> Leer -> Oefen -> optional Check -> Verdiep
```

It should not show every artifact as a peer card.

Secondary surfaces remain available, but behind collapsed route groups:

- `Verdiep je begrip`
- `Lesboek en bronnen`
- `Docent/downloads`
- `Volledige vaardigheidskaart` when a full skill-tree page exists

## Game Row Rule

The `Oefen` layer consumes the shared skill-map/game architecture:

- `Redeneren` uses the reasoning game route.
- `Rekenen` uses the procedure/stappenplan route when present.
- `Grafieken` uses the graphical game route when present.
- The old full `wiskundevaardigheden` skill-tree page is not the default
  `Rekenen` route when a procedure/stappenplan game exists.
- A paragraph without a graphical game must not promise graph practice.

## Check Rule

The `Check` layer is supported by the contract but hidden in current Book 1
output because the exit-ticket MVP is paused after L1.7B.

The generator may show `Check` only when a real exit-ticket file exists. It must
not render placeholder check cards that imply a completed checkpoint.

## Boundary Language

Landing copy may use:

- `oefenroute`
- `oefenvoortgang`
- `verder oefenen`
- `start`, `leer`, `oefen`, `verdiep`

Landing copy must not use:

- `diagnose`
- `adaptief`
- `beheersing`
- `persoonlijk leerpad`
- `geslaagd` / `gezakt`
- `score als cijfer`
- `AI`
- `summatief`
- `PV`

## Human Review Focus

The human review should decide whether:

- the first visible route answers "what should I do first?";
- the primary route is not overloaded;
- secondary surfaces are still findable;
- `Oefen` reads as three scoped practice options, not a full catalog;
- the absence of an exit ticket does not confuse students;
- the page remains usable on desktop/mobile and in light/dark modes.
