# L1.7B-R Stop Decision

Date: 2026-05-25
Status: PAUSED; PLATFORM SUPPORT REQUESTED

## Decision

Stop L1.7B-R before implementation.

The lesson-side resume path has enough information to define the boundary-safe
MVP, but it should not implement platform engine/runtime work directly from the
lesson repo. The platform reference roadmap already identifies `GAME-UX-2` as
the required platform support lane for this exact work.

## Why This Stop Is Required

1. The prior prototype remains untracked design evidence, not accepted source.
2. The prototype semantics include mastery/pass/score/evidence/adaptive-focus
   language and behavior that are explicitly blocked.
3. The platform roadmap says `GAME-UX-2` is future platform support for lesson
   L1.7B-R and awaits a lesson support request plus upstream platform-gate
   resolution or waiver.
4. Implementing the engine from the lesson side would blur the repository
   boundary and risk hand-built product logic in the generated lesson target.

## What Was Completed

- L1.7B-R operational sprint plan was created.
- Baseline audit was recorded.
- Platform support request for `GAME-UX-2` was written.
- No generated lesson output was changed.
- No platform runtime code was changed.
- The untracked prototype zip remained untracked and untouched.

## What Remains Open

L1.7B-R MVP implementation remains open until platform confirms an active,
approved support lane and completes or authorizes:

- source-controlled checkpoint runtime;
- source-controlled pilot data route;
- shell generator and deploy integration;
- validation and screenshot/interaction QA;
- regenerated lesson output;
- L1.7B-R human-review packet and records.

`GATE-L1.7B` remains blocked until that generated, reviewed output exists.

## Boundary Confirmation

This stop decision authorizes no:

- exit-ticket implementation;
- generated lesson-output mutation;
- broad companion scaling;
- target-exercise promotion;
- CP-6 closure;
- Year 1 closure;
- diagnostics;
- adaptive routing;
- mastery decisions;
- automatic sequencing;
- grading or summative use;
- student-facing AI;
- PV projection;
- PV machine promotion.

## Next Action

Platform should decide whether and when `GAME-UX-2` can become active. If it
remains blocked by GATE-EX5 or another platform prerequisite, that blocker
should be stated in the platform roadmap before lesson L1.7B-R resumes.
