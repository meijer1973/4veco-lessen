## Work Procedure

1. Confirm the current roadmap state and evidence files.
2. Record an evidence inventory, distinguishing current proof from historical
   proof and carried flags.
3. Run current validation that is proportionate to a roadmap decision sprint:
   paragraph validators for `1.1.1` through `1.1.3`, Book 1 health,
   print-scope, v5 target-exercise count, and procedure-contract validation.
4. Build a readiness matrix for:
   - Part A textbook print/web;
   - landing pages;
   - procedure contracts;
   - semantic visual adequacy;
   - presentation-v2;
   - begeleide inoefening;
   - graphical game;
   - three-aspect game row;
   - inert adaptive seam;
   - target exercises;
   - PV/A61 boundaries;
   - validation/review workflow.
5. Classify every visible flag as `fix_now`, `carry_forward`, or `defer`.
6. Record the scaling decision:
   - broad scaling: yes/no;
   - controlled next-step production: yes/no/conditions;
   - next lesson sprint.
7. Update the roadmap without changing generated output.

## Stop Conditions

Stop rather than close if:

- current validators for the first three companion paragraphs fail;
- L1.6R evidence is missing or contradicts the quality ref;
- any artifact claims broad scaling is approved without the later L1.7B,
  L1.7C-0, L1.7C, L1.7D, L2.0, and Scale Gate sequence;
- any artifact weakens the blocked-use boundaries for diagnostics, adaptive
  routing, mastery, sequencing, student-facing AI, summative use, PV projection,
  or PV machine promotion;
- the decision depends on target-exercise final review, protected reference
  mutation, or unit minting.
