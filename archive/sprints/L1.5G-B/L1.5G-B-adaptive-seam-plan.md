## Work

1. Add a platform-owned adaptive seam helper.
   - One localStorage key.
   - Schema version `1`.
   - Safe parsing and normalization.
   - Default/empty payload that cannot change game behavior.
2. Wire the five existing game engines to read the helper and store the
   resulting payload internally.
   - Quiz.
   - Nieuws-detective.
   - Redeneer-spel.
   - Wiskundevaardigheden / skilltree.
   - Stappenplan / procedure.
3. Update shell generation and deploy copy list so the helper is available in
   generated lesson output.
4. Add focused tests.
   - Helper handles missing, malformed, wrong-version, and valid payloads.
   - Every engine exposes the same default payload when no storage is present.
   - Empty/default payload does not alter existing engine setup.
5. Deploy Book 1 through `scripts/deploy.js` if shell output changes.
6. Update roadmap and write a closure log.

## Stop Conditions

Stop if implementation:

- changes game selection, scoring, question count, skill visibility, or
  procedure behavior when the payload is absent/default;
- requires a real advisor or diagnostic decision;
- shows adaptive claims in student-facing UI;
- exposes internal PV IDs or PV projection to students;
- requires mutation of protected reference data;
- needs hand edits inside generated lesson output.
