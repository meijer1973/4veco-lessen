## Process Finding

The procedure-contract validator remains useful but insufficient. L1.6R adds
the stricter rule used here:

```text
procedure_contract_pass != lesson_surface_pass
```

For visual skills, a procedure must be paired with:

```text
Procedure + worked visual example + student action
```

The L1.6R remediation now satisfies that standard for the remediated `1.1.3`
companion surfaces in technical/semantic QA. Human review accepted the
guided-practice concordance correction.
