## Product Scope

### Presentation

Minimum required slide evidence:

- Startvraag: actual ice-cream table next to an actual P-Q graph.
- Tabelwaarden: table with highlighted headers, row labels, and selected
  values.
- Assen: P-Q axes with price on the vertical axis, quantity on the horizontal
  axis, and a plotted point such as `(300; 2,00)`.
- Aflezen/interpoleren: graph with guide lines from `P = 1,75` to
  approximately `Q = 350`.
- Kritisch kijken: two versions of the same data, one with a zero baseline and
  one with a truncated vertical axis.

Procedure route strips may remain, but not as the only visual content.

### Uitleg Vaardigheden

Each core route must pair a concrete visual object with the procedure:

- table-value route: table with highlighted source values;
- graph-drawing route: P-Q graph from table points;
- graph-reading route: interpolation graph with guide lines;
- misleading-axis route: two graph panels with different vertical-axis scales.

### Begeleide Inoefening

Every guided exercise that asks students to inspect a graph or table must show
the source object in the guided page:

- bread-roll graph;
- coffee table plus blank axes template;
- cinema interpolation graph;
- water two-point graph;
- misleading-axis graph comparison.

### Other Companion Surfaces

- Uitleg voorkennis: add a small coordinate/P-Q visual.
- Samenvatting: add a mini P-Q graph and a misleading-axis reminder.
- Nieuws met visual: replace the simplified mini-chart with two explicit graph
  panels: zero-baseline and truncated-axis.

## Stop Conditions

Stop rather than close if:

- a main graph/table explanation surface lacks the visual object it teaches;
- the presentation still explains graphs/tables with only text or route cards;
- guided practice requires a graph/table but does not show it;
- the platform cannot regenerate the visual surfaces without hand patches in
  the lesson repo;
- screenshot QA only checks overflow/theme and does not record semantic visual
  adequacy;
- review records do not include the required visual-evidence table;
- L1.6R expands into a broad redesign beyond `1.1.3` remediation and the
  necessary reusable gate.
