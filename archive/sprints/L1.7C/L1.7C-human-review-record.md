## Main Finding

for example `Volgende focus: A61`. This directly affected the L1.7C feature
under review because the route panel is meant to answer what the student should
practise next in ordinary language.

   internal skill ID.
2. Add a regression test using an internal ID such as `A61` and assert that the
   visible text contains the readable label and not the ID.
3. Regenerate the Book 1 shared runtime and affected game pages through the
   platform workflow.
4. Add route-panel screenshot evidence or carry the lack of screenshot proof as
   a lead-review flag.
5. Correct the `1.1.1` landing-page wording so it does not imply a graph route
   where none exists.
