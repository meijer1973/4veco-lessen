# L1.7B-P23 Operation-Chain Analysis

Date: 2026-05-26
Status: COMPLETE; PLATFORM HANDOFF REQUIRED

## Summary

The `1.1.2` and `1.1.3` target exercises require more than choice tasks. A
valid exit ticket needs calculation input, final-answer notation, units,
table/graph value handling, graph-specific interaction, and short explanation.

The current exit-ticket engine supports only choice tasks, so generated
checkpoint output should not be produced in this sprint.

## `1.1.2 Percentages en indexcijfers`

Target exercise:

| Subquestion | Required operation chain | Required answer form |
|---|---|---|
| a. Bicycle price rises from EUR 800 to EUR 920; calculate percentage change. | Identify old value `800`; identify new value `920`; calculate difference `120`; divide by old value; multiply by 100; interpret as a 15% increase. | Calculation/work field, final numeric answer, percent notation, increase/decrease wording. |
| b. Basket costs EUR 150 in 2023 and EUR 162 in 2025; calculate 2025 index with 2023 = 100. | Identify base-year value `150`; identify target-year value `162`; divide target by base; multiply by 100; interpret index `108`. | Calculation/work field, final index answer, no percent sign. |
| c. Index rises from 108 to 112; calculate price increase from 2025 to 2026. | Identify old index `108`; new index `112`; calculate difference `4`; divide by old index; multiply by 100; round to 3.7%. | Calculation/work field, final percent answer, rounding evidence. |
| d. Student claims 108 to 112 means 4% inflation; explain and calculate correct figure. | Distinguish 4 index points from percent change; apply percentage-change formula to index values; explain why the claim is wrong; give 3.7%. | Short explanation plus calculation and final percent answer. |

Required coverage:

- `A38 Procentuele verandering berekenen`
- `A39 Prijsindex (CPI) berekenen`
- `D31 Indexpunt versus procentuele verandering`

Design consequence:

`1.1.2` cannot be checked honestly with choice tasks only. Choice questions can
ask whether a formula or answer is correct, but they do not prove the student
can select values, perform the calculation, write notation, and explain the
index-point trap.

## `1.1.3 Grafieken en tabellen`

Target exercise:

| Subquestion | Required operation chain | Required answer form |
|---|---|---|
| a. Draw the ice-cream table as a graph with price vertical and quantity horizontal. | Read table; identify variables and units; apply economic axis convention; choose scale; plot points; connect appropriately. | Graph-building interaction or structured axis/point placement evidence. |
| b. Read from the graph how many ice creams are sold at EUR 1.75. | Locate EUR 1.75 between EUR 1.50 and EUR 2.00; interpolate between 400 and 300; answer approximately 350 ice creams. | Graph-reading/interpolation numeric field with approximate-answer support. |
| c. Newspaper says sales dropped by 50%; identify between which prices and explain. | Read table values; search pairs; calculate percentage drops; identify at least `400 -> 200` from EUR 1.50 to EUR 2.50, and possibly `200 -> 100` from EUR 2.50 to EUR 3.00; explain using the table. | Table-value selection, percentage calculation, short explanation. |

Required coverage:

- table heading / row / column / unit reading;
- economic axis convention;
- graph drawing;
- graph reading;
- interpolation;
- percentage-claim evaluation.

Current registry note:

The active target-exercise record lists `A38` and flags graph drawing plus graph
reading/interpolation as missing-unit needs. The paragraph plan and generated
skilltree data already name `A61/A62/A63/A38/A39` as the broader learning route.

Design consequence:

`1.1.3` cannot be checked honestly with choice tasks only. A valid readiness
check needs graph/table interaction or a reviewed substitute that captures
value selection, interpolation, graph convention, and explanation.
