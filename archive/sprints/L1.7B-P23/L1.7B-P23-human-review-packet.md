## Review Scope

L1.7B-P23 reviews the stop/handoff decision for `1.1.2` and `1.1.3`
exit-ticket checkpoint designs.

The review should decide whether the sprint was correct to stop rather than
generate choice-only checkpoint output, because the target-exercise operation
chains require task types the current exit-ticket engine/UI do not support.

This packet is not itself the review record. L1.7B-P23 is not closed until
formal review records and the lead-review summary exist.

## Original Specification

The exit ticket should check whether the student is ready to try the paragraph
target exercise. It must cover the target skills, decompose the target exercise
into operations, use task forms that match the skill type, and give neutral
next-step feedback.

For `1.1.2`, that means calculation and notation.

For `1.1.3`, that means graph/table handling, interpolation, and explanation.
