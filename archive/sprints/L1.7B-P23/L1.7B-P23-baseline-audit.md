Date: 2026-05-26
Status: COMPLETE

## Scope

L1.7B-P23 checks whether exit-ticket checkpoint designs for `1.1.2` and
`1.1.3` can be produced now without weakening the exit-ticket specification.

The baseline is:

- `L1.7B-MAP` closed PASS WITH FLAGS and fixed `1.1.1` metadata alignment.
- `L1.7C-MATH` closed PASS WITH FLAGS and restored the scoped math skill-tree
  game as the primary `Rekenen` route.

- `specifications/product-end-state.md` says exit tickets should check
  readiness for the paragraph target exercise before readiness language is
  allowed.

## Source Evidence

### `1.1.2 Percentages en indexcijfers`

Paragraph plan target skills:

- calculate percentage change using old value as base;
- calculate and interpret index numbers;
- distinguish index points from percentage changes;
- use index numbers in economic contexts.

Target-exercise registry required skills:

- `A38`
- `A39`
- `D31`

Generated practice support currently includes:

- procedure data for percentage change, index number, and index-point versus
  percentage distinction;
- scoped skilltree data with active skills `A38/A39`;
- no exit-ticket source data or generated exit-ticket output.

### `1.1.3 Grafieken en tabellen`

Paragraph plan target skills:

- read tables by heading, row label, column label, and unit;
- draw a price-quantity graph using the economic axis convention;
- read and interpolate values from a graph;
- use graph/table values in percentage and index calculations;
- judge graph or percentage claims.

Target-exercise registry required skills:

- `A38`, with missing-unit flags for graph drawing and graph reading /
  interpolation.

Generated practice support currently includes:

- procedure data for table-value selection and graph reading;
- graphical-game data for graph reading and graph-value percentage change;
- scoped skilltree data with active skills `A61/A62/A63/A38/A39`;
- no exit-ticket source data or generated exit-ticket output.

## Engine/UI Capability Baseline

The current platform exit-ticket engine validates only choice tasks:

```text
task.type === "choice"
```

The current UI renders tasks as option buttons and does not provide:

- calculation/work fields;
- final-answer numeric fields;
- unit or percentage notation fields;
- table-value selection widgets;
- graph-reading widgets;
- graph-drawing or point-plotting widgets;
- short constructed-response fields.

## Landing/Activation Baseline

No platform source exists for:

- `source-data/book-1/exit-ticket/1.1.3.json`

## Baseline Decision

The sprint should not generate `1.1.2` or `1.1.3` exit-ticket output with the
current engine. The operation chains require task forms that the current engine
and UI do not support.
