# L1.5G-A MVP Data Model Sketch

This is a sketch for L1.5G-C. It is not a committed schema and it should not be
used by generated lesson output until L1.5G-C creates a validator.

## Required Validator Checks

The L1.5G-C validator should check:

- unique challenge IDs;
- allowed challenge `type`;
- graph data has labels, units, and numeric values;
- expected answer matches the challenge type;
- feedback uses the order `bron -> waarden -> berekening` where calculation is
  present;
- no student-facing title, prompt, hint, or feedback contains PV/internal codes;
- `internal_pv_boundary.student_facing_pv_projection` remains `false`;
- no adaptive, diagnostic, mastery, sequencing, AI, or summative flags are
  enabled.

## Initial Challenge Types

| Type | Student action | L1.5G-C status |
| --- | --- | --- |
| `bar_value_read` | Read one value from a bar chart. | MVP |
| `line_value_read` | Read one value from a line chart. | MVP |
| `graph_values_percentage_change` | Select old/new values and calculate percentage change. | MVP |
| `table_to_bar_match` | Match a table to the correct bar chart. | Optional stretch |
| `pie_share_point_change` | Distinguish percentage points and percentages in pie charts. | Deferred |
| `producer_profit_graph` | Read producer/profit graph values. | Deferred |
| `market_equilibrium_graph` | Read/manipulate market equilibrium graph. | Deferred |

## Adaptive Seam Interaction

The graphical game should not define its own adaptive state. L1.5G-B should
first define a shared read helper and localStorage payload. L1.5G-C should only
read that helper and behave identically when the payload is absent or default.

## Generated Output Expectation For L1.5G-C

The later implementation sprint should produce, through the platform workflow:

- platform engine files under `4veco-platform/engines/`;
- a shell generator under `4veco-platform/build-scripts/platform/`;
- shared data under the target lesson book's `shared/` tree;
- a generated paragraph game page reachable from the paragraph landing page;
- tests and validators in the platform repo.

L1.5G-A intentionally produces no generated lesson output.
