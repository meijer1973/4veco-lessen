## Work Procedure

1. Record the baseline audit for the Book 1 Chapter 1.1 pilot state.
2. Define the PASS WITH FLAGS operational meaning and quality-ref status
   language standard.
3. Define the student-web house-style baseline:
   landing route layers, companion completion contract, dual-coding minimums,
   procedure consistency, game-row limits, shared skill-map use, screenshot QA,
   and exit-ticket readiness.
4. Classify carried flags as:
   - `fix_before_scale`
   - `carry_into_controlled_production`
   - `defer`
5. Implement the consolidation landing-page rule through the platform generator
   only if the baseline confirms the existing `1.1.4` page is a route-semantic
   defect, not a content defect.
6. Regenerate affected landing output through the platform workflow.
7. Run focused and current validators.
8. Prepare human-review packet. Do not close L2.0 without review records and a
   lead-review summary.

## Consolidation Landing Rule

For `type: consolidation` or title/name containing `Gemengde opgaven`, if the
page has textbook exercise/answer output but no ordinary companion route, the
landing page should expose a primary `Oefen gemengd` layer instead of burying
the exercise set under `Verdiep`.

The rule must remain conservative:

- it may route to existing opgaven/antwoorden output;
- it may not invent missing companion pages;
- it may not expose `Check` unless a reviewed exit-ticket surface exists;
- it may not imply diagnostics, mastery, sequencing, grading, summative use,
  student-facing AI, PV projection, or PV machine promotion.

## Acceptance Criteria

- L2.0 policy records exist and are specific enough to guide future paragraph
  builds.
- `PASS WITH FLAGS` has an operational definition.
- Game-row MVP flags from L1.7C are classified and not hidden.
- L1.7D landing route rules are captured for reuse.
- Exit-ticket readiness is captured as a checklist for L1.7B-R/GATE-L1.7B.
- Quality-ref status language is standardized without falsely upgrading
  legacy evidence.
- Future screenshot/QA expectations are explicit.
- `1.1.4 Gemengde opgaven` no longer presents as a `Verdiep`-only landing page
  after regeneration.
- Broad companion scaling remains blocked.

## Stop Conditions

- Stop if any change would hand-edit generated landing HTML instead of changing
  the platform generator.
- Stop if the consolidation landing rule requires new lesson content rather
  than routing existing exercise output.
- Stop if quality refs would need false upgrades or stale evidence hiding.
- Stop if the sprint starts implementing exit-ticket, full numeric calculation,
  broader graph variants, or new companion surfaces.
- Stop if any artifact claims Scale Gate 1, CP-6, Year 1, broad companion
  scaling, diagnostics, mastery, sequencing, summative use, student-facing AI,
  PV projection, or PV machine promotion.
