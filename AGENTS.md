# 4veco Lessons — Agent Entry

This repository contains authored lesson content and student-facing outputs
for VWO economics. Read the shared
[platform operating guide](https://github.com/meijer1973/4veco-platform/blob/main/AGENTS.md)
first (local: `../4veco-platform/AGENTS.md`). It owns worktree safety, source
authority, task routing, review and publication boundaries for both repositories.

## Lesson-specific boundaries

- Edit lesson source where its workflow assigns ownership here. Repair
  generated files through platform tools; copied `shared/` runtime code is
  owned by platform. Do not introduce lesson-local replacements for its tools.
- Book 1 is frozen. New material uses the markdown-native `Boek N - titel/`
  route and current teaching authority.
- Claim this worktree through the platform preflight with `--worktree`.
  When both repositories change, keep their owned worktrees together under
  the task folder and record both commits.
- The companion product route is `Start -> Leer -> Check -> Oefen -> Exit ticket`.
  Its full acceptance requirements live in the
  [product end state](specifications/product-end-state.md) and
  [companion specifications](specifications/companion-core-specifications.md).

## Start with the assignment

| Assignment | Route |
|---|---|
| Inspect existing content | Affected files; [lesson map](RESEARCH_AGENT_MAP.md) for unfamiliar locations. |
| Textbook authoring or review / Part A | [Part A checklist](https://github.com/meijer1973/4veco-platform/blob/main/docs/workflows/part-a-start.md), including reproduction of an unchanged edition. |
| Companion / Part B | [Companion runbook](https://github.com/meijer1973/4veco-platform/blob/main/docs/workflows/web-companion-paragraph-lane.md). |
| Chapter/book assembly | [Chapter workflow](https://github.com/meijer1973/4veco-platform/blob/main/BUILD-CHAPTER.md) and the chapter plan. |
| Complete cross-lane verification | [Complete paragraph workflow](https://github.com/meijer1973/4veco-platform/blob/main/BUILD-PARAGRAPH.md). |
| Maintenance or integration | The shared guide's matching maintenance, Part A or protected/product route. |
| Roadmap or product decisions | Relevant roadmap and original requirements, [vision](specifications/product-vision.md), [end state](specifications/product-end-state.md), and the shared guide's applicable review procedure. |

Load a workflow and its references when its scope applies. Maps, chapter
manuals and historical reports are not universal startup reading. Cross-repo
links open GitHub `main`; use the same paths in `../4veco-platform/` locally.

Search current source first. [Archive navigation](archive/README.md) holds
historical evidence, not current operating instructions. Archiving does not
close open obligations.
