failure.

L1.6 remains technically useful as a fresh-build, procedure-contract,
graphical-game, and inert-adaptive-seam proof. The student-facing companion

## Findings

- The textbook Part A source contains the core table and graph assets.
- The generated companion presentation explains tables and graphs mostly with
  text and procedure cards, without the concrete visuals students need.
- `Uitleg vaardigheden` gives procedure routes without actual table/graph
  examples.
- `Begeleide inoefening` refers to graph/table exercises without consistently
  embedding the source graph or table.
- Technical screenshot QA checked rendering and layout, but not semantic visual
  adequacy.
- Procedure-contract validation worked, but procedure correctness is not the
  same as learning-object adequacy.

## Process Lesson

For graph/table paragraphs:

```text
procedure_contract_pass != lesson_surface_pass
```

A surface must show the object the student is learning to use. For visual
skills, the minimum unit is:

```text
procedure + worked visual example + student action
```
