## Build Procedure

1. Read 1.1.2 Part A markdown, assets, review, quality-ref, and unit registry entries for the relevant skills.
2. Write or update platform source scripts for 1.1.2 companion artifacts.
3. Generate direct student-facing HTML for rich companion pages.
4. Generate interactive data files and run platform shell builders.
5. Generate the PPTX and write the semantic presentation-v2 HTML from the same platform source.
6. Regenerate landing pages so tile labels remain user-facing and no Word download affordances return.
7. Validate:
   - `node scripts/validate-paragraph.js --mode part-a --profile publisher-print <paragraph>`
   - `node scripts/validate-paragraph.js --mode complete --profile student-web <paragraph>`
   - platform data tests where affected
   - link checker if deploy is run
8. Review final diffs for:
   - no student-facing internal unit codes
   - no visible `HTML` tile badges
   - no default Word download options
   - no missing companion outputs
   - presentation notes suitable for later text-to-speech work

## Stop Conditions

Stop before commit if:

- student-web validation fails for 1.1.2
- Part A publisher-print validation regresses
- generated landing page reintroduces Word download links as default lesson-tile options
- student-facing pages expose internal unit codes
- presentation HTML is missing, visibly incomplete, or fails presentation-v2 screenshot QA
- source/output parity breaks on the percentage/index procedures
